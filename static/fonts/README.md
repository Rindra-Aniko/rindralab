# Petunjuk File Font Lokal

Tempatkan file font Anda di dalam folder ini (`static/fonts/`):

### 1. Quattrocento Sans (Default Font)
- `QuattrocentoSans-Regular.woff2` (atau `.ttf`)
- `QuattrocentoSans-Bold.woff2` (atau `.ttf`)
- `QuattrocentoSans-Italic.woff2` (atau `.ttf` - opsional)
- `QuattrocentoSans-BoldItalic.woff2` (atau `.ttf` - opsional)

### 2. Poppins (Opsional / Tersedia jika dibutuhkan)
- `Poppins-Regular.woff2` (atau `.ttf`)
- `Poppins-Medium.woff2` (atau `.ttf`)
- `Poppins-SemiBold.woff2` (atau `.ttf`)
- `Poppins-Bold.woff2` (atau `.ttf`)

> Font format `.woff2` sangat direkomendasikan karena ukurannya yang paling efisien dan didukung oleh semua browser modern.
